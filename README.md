# Prairie Trails Website

## About
This is my SODV 1401 project. It includes three parts.

## Part 1 – Website
- Responsive HTML and CSS website.
- Includes images, a table, form, and FAQ.

## Part 2 – Enquiry Form
- JavaScript checks user input.
- Shows errors and a success message.
- Sanitizes data before displaying it in the console.

## Part 3 – Map and Weather
- OpenStreetMap shows Calgary area trails.
- Open-Meteo provides live weather.
- Handles errors and timeouts.
- Uses optimized images and minified code.

## How to Run
1. Open the project in VS Code.
2. Start Live Server.
3. Open the index.html file for each part.
4. Internet is needed for the map, weather, and fonts.

## Privacy
- The map loads when the user clicks the button.
- External services may receive the user's IP address.
- No API keys are exposed.
- Form data stays in the browser.

## Testing
- Tested in Edge and on mobile layouts.
- Part 3 Lighthouse scores: 100 in all four categories.
